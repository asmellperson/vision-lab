# 架构与实施计划

## 架构

- `frontend/`：React + TypeScript + Vite，目录、学习路径、统一实验页、模型页、实验历史、流水线。参数和输入要求来自后端元数据。
- `backend/app/algorithms/`：注册表、传统算子、工业/三维、视频处理。统一返回底图、独立图层、数据和下载产物。
- `backend/app/models.py`：版本化模型清单、文件校验、按需加载、单设备互斥与缓存释放。
- `backend/app/jobs.py`：SQLite 持久任务与后台工作线程，排队、进度、取消、错误、重启恢复。
- `backend/app/main.py`：上传、素材、实验、预览、模型下载、参数方案、流水线 REST API。
- `data/`：运行时上传、SQLite、实验产物；`models/`：本地权重与配置；`assets/examples/`：可复现示例素材。

## 阶段与验收

1. [x] 基础框架：端到端上传 → 参数 → 执行 → 对比 → 下载；SQLite 历史与方案。
2. [x] OpenCV：图像基础、增强、阈值、形态学、边缘、形状、几何、特征与匹配，具名算子单独入口。
3. [x] 模型：22 套真实预训练模型适配及预下载、完整文件清单、离线推理、失败隔离、资源释放。
4. [x] 专项：工业参考库、像素/尺度测量、视频时序/事件、标定/双目/两视图/点云。
5. [x] 流水线、评估与验收：有效连接、步骤产物、真值指标、实际素材、前端构建和浏览器操作。

每个算法均声明输入、参数、输出、原理、用途和失败条件。未实现/环境阻塞项不能声称完成，记录于 FEATURES.md。

## 功能边界约定

- 所有坐标对应 EXIF 方向修正后的原图；前端以 SVG viewBox 映射。
- mask 原始标签与彩色可视化分别保存；叠加图层可开关。
- 普通逐帧算法与真正时序算法显式区分；视频用 FFmpeg 规范化 CFR，再按相同 fps 输出 H.264/AAC。
- 尺寸默认 px；有尺度才输出 mm；单目深度标注相对尺度。
- 无真值只显示预测与耗时；工业规则与通用模型类别不可混淆。
- 推理禁止隐式下载；联网只发生在显式模型准备/下载阶段。
