# 首页与实验工作台界面

首页用于查找和进入算法实验，Canny 工作台以原图和处理结果为主要内容。以下规范描述这两个页面的布局与样式。

## 页面布局

首页依次展示算法搜索、常用实验和四类算法入口：传统视觉、深度学习、工业视觉、视频与三维。分类中的算法来自后端注册信息，支持按名称、英文 ID 和用途搜索。

Canny 桌面布局分为左侧算法导航、中间实验画布和右侧参数工作台。导航宽约 224px，参数区通常为 288px，大屏下为 304px，剩余空间用于原图与结果。参数面板可折叠，画布随可用窗口尺寸调整。

素材和查看工具位于画布上方，结果下载和学习标签页位于下方。窄屏下导航收起，参数与画布改为纵向排列；长代码在代码区域内滚动。

## 颜色与排版

| 用途 | 颜色 |
| --- | --- |
| 页面背景 | `#f4f6f6` |
| 内容表面 | `#ffffff` |
| 正文 | `#182525` |
| 次要文字 | `#586768` |
| 主操作与焦点 | `#087f75` |
| 图像查看区域 | `#182124` |

中文字体依次使用 Noto Sans CJK SC、Noto Sans SC、苹方、微软雅黑及系统无衬线字体。页面标题约 25–28px，模块标题 18px，正文与控件 14px，辅助文字 12–13px。常用间距为 4、8、12、16、24、32px。

模块主要通过留白、背景和字体层级区分。输入控件保留边界，常用圆角为 4–5px。青绿色用于主要操作、选中标记与键盘焦点，图像区域使用深色背景。

## 控件与交互

- 算法目录突出一级分类，二级入口使用紧凑列表；选中项以细竖线和字重标识。
- 查看模式使用紧凑的并排、滑动和单图切换，缩放控件与其放在同一工具栏。
- 参数名称、滑块、数字框和说明按组排列。「运行实验」是参数面板中的主要操作。
- 原理与结果解读、Python 示例、结果数据、同素材对比使用文字标签页，当前标签以下划线标识。
- 键盘焦点保持可见，禁用、加载、失败和结果过期状态使用明确文字提示。

## 样式组织

公共字体与控件位于 `frontend/src/theme.css`。`lab.css` 通过 `.lab-pilot` 限定首页与 Canny 的颜色和导航样式，`workbench.css` 通过 `.workbench-page` 限定 Canny 的布局。其他算法页面使用公共样式。

图标使用 `lucide-react`。算法目录、参数表单和实验交互继续由现有组件与注册信息驱动。
