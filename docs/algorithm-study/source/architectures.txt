@@ resnet18
ResNet18｜残差卷积分类骨干
→ RGB 224×224 → 7×7卷积/池化 → 四组BasicBlock → 全局平均池化 → 1000类线性层
输入与 stem：常规分类使用权重配套缩放、中心裁剪和标准化。224×224 输入经 7×7、步长 2 卷积得到 64×112×112，再经最大池化得到 64×56×56。
残差 stage：layer1–4 分别含两个 BasicBlock，典型输出依次为 64×56×56、128×28×28、256×14×14、512×7×7。每块主支路是两次 3×3 卷积及归一化、激活；降采样时捷径用投影匹配尺寸。
分类输出：全局平均池化把每个通道压成一个数，512 维向量经全连接得到 1000 个 logits。训练常用交叉熵，推理 softmax 后选 top5；softmax 不改变最大类别排序。
项目任务分支：anomaly 取 layer2 和 layer3，将后者上采样到 28×28，再拼为 384 通道并局部平均池化；gradcam/feature_maps 取 layer4。它们使用同一骨干，但后处理与预处理不等于分类入口。
架构取舍：残差连接改善优化和特征复用，深层下采样增强语义却降低空间精度；因此不能直接把最后一层格点当原图精确轮廓。
来源：backend/app/models.py、backend/app/inference.py；R02。
@@ yolov8n
YOLOv8n｜单阶段多尺度检测
→ letterbox → Conv/C2f骨干与SPPF → 上下行特征融合 → 解耦检测头 → 解码与NMS → 原图框
输入与骨干：项目图像检测 imgsz=640。按比例缩放并填充后，步长卷积逐级下采样，C2f 将特征分支经过瓶颈再拼接，SPPF 在深层以串联池化汇聚不同感受野。
颈部：上采样与横向拼接把深层语义传给高分辨率层，再以下采样路径融合定位信息，形成典型 P3/P4/P5 检测特征。640 的方形输入对应约 80×80、40×40、20×20 网格。
解耦头：每个尺度有类别与框回归通路。anchor-free 使用特征网格参考点，框距离采用分布式回归表达；它不应被讲成旧 YOLO 的固定 anchor 加独立 objectness 五参数格式。
训练与推理：训练使用任务分配、分类损失、IoU 类定位损失和 DFL 等；推理解码候选，做置信度过滤与 NMS，再将坐标反映射到原图。NMS 阈值与展示 confidence 是不同参数。
项目扩展：multi_track 在框后增加关联器，events 再增加事件状态，sequence 再增加顺序状态机；这些规则层不属于 YOLO 神经网络内部。
来源：backend/app/inference.py、backend/app/video.py；R03、R04。

@@ yolov8n-seg
YOLOv8n-Seg｜原型式实例分割
→ YOLOv8多尺度特征 → 检测头 + 原型分支 + 系数分支 → 每实例掩膜 → 去填充与原图对齐
检测通路：共享骨干与颈部仍输出实例框、类别及分数，用于确定哪些对象需要掩膜。

输出恢复：letterbox 的填充必须正确去除，掩膜按原图宽高恢复。项目保存像素实例标签，单张标签图遇到重叠时无法同时表达同一像素的多个实例归属。
学习重点：理解原型共享为何省计算、掩膜损失与框损失为何并存，以及类别 ID 和实例 ID 的区别。
来源：backend/app/inference.py；R03。

项目证据：加载函数明确为 deeplabv3_mobilenet_v3_large，不能把常见 ResNet 版本架构套进本项目。

→ 文字检测 → 四边形裁剪矫正 → 方向分类 → 文字特征编码 → CTC字符解码

DocLayout-YOLO｜YOLOv10 文档区域检测架构
→ 页面缩放 → Conv/C2f与G2L_CRM → SCDown、SPPF与PSA → 上下采样及多尺度融合 → v10Detect区域检测
骨干组成：本地权重记录为 YOLOv10DetectionModel，对应 yolov10m-doclayout.yaml。前段 Conv 与 C2f 提取局部特征，G2L_CRM 在不同层整合上下文，SCDown 分解通道调整与空间下采样；高层接 SPPF 空间池化和 PSA 部分自注意力。
全局到局部模块：G2L_CRM 先投影并分支，串接若干瓶颈后拼接输出。浅中层的空洞分支使用同一卷积权重、不同 dilation 获得不同感受野，再以门控融合；既覆盖较大版面范围，也保留文字块局部线索。此处“全局”不意味着每层都做全页 Transformer 注意力。
多尺度融合：上采样后的高层特征与骨干较浅层拼接，经过 C2f 细化；再向下采样，用 C2fCIB 等模块融合，形成步长约 8、16、32 的三组特征。小字号区域依赖高分辨率分支，大图片、表格依赖语义较强的低分辨率分支。
任务头与输入：三尺度特征进入 v10Detect，预测区域类别与框；其中 DFL 将边界距离分布转为连续回归值。项目使用 DocStructBench 权重、imgsz=1024。多样化合成页面属于训练数据策略，并不是推理网络中的额外输入模块。
输出边界：标题、正文、表格等区域类别不直接提供单元格结构和阅读顺序，后续还需 OCR 与文档结构推断。
来源：models/layout/doclayout.pt 的架构元数据、本地 doclayout_yolo 配置与 g2l_crm.py、backend/app/inference.py；R12。

CLIP ViT-B/32｜视觉与语言双编码器
→ 图像ViT与文本Transformer独立编码 → 各自投影为512维 → L2归一化 → 余弦相似度

文本分支：tokenizer 把文本转成 token 并加位置表示，经过 12 层、隐藏维 512、8 头的文本 Transformer。使用序列聚合表示再投影到与图像一致的 512 维空间。

架构边界：两分支在编码时独立，没有像 VQA 那样逐 token 的图文交叉注意力；也没有框回归或语言生成头。

→ 3×3重叠嵌入 → 四级编码器 → 潜层 → 跳接解码器 → 细化块 → 残差RGB输出

GDFN：1×1 投影扩展通道，深度卷积后分成两路，一路经 GELU 与另一路逐元素相乘，再投影回原通道。门控选择特征，扩展系数 2.66。
残差块：每个块依次执行归一化+MDTA 的残差更新、归一化+GDFN 的残差更新；末端四个细化块与 RGB 输出卷积完成恢复。
去噪特有配置：BiasFree 归一化按本地实现除以标准差并乘权重，不等同于只删掉常规 LayerNorm 偏置；真实去噪权重与运动去模糊权重不能互换。
来源：models/swin-denoise/config.yml、models/swin-denoise/restormer_arch.py；R19、R20。

→ RGB嵌入 → 多尺度MDTA/GDFN编码 → 跳接解码 → 4个细化块 → 清晰图残差

U2NetP｜嵌套U形显著前景网络

R3D18｜三维残差视频分类
