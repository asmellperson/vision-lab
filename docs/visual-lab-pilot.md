# 首页与 Canny 视觉试点

范围：仅首页内容、这两页的导航外观及 Canny 展示样式。保留 Experiment、Viewer、参数控件、API、路由和动态算法目录的实现。其他页面继续使用原样式。

## 设计基线

- 画布底色 `#f4f6f6`，内容表面 `#ffffff`，正文 `#182525`，次要文字 `#586768`，操作主色 `#087f75`，图像查看器 `#182124`。
- 沿用 Noto Sans CJK SC / 苹方 / 微软雅黑中文字体。页面标题 26px，模块标题 18px，正文与操作 14px，辅助说明 12–13px；使用 400 / 500 / 600 字重。
- 桌面导航约 224px，参数区 288px，剩余宽度全部交给实验区。画布随可用宽高增长，不以 1920px 页面宽度或 480px 画布高度封顶。
- 留白以 4 / 8 / 12 / 16 / 24 / 32px 组织。输入框保留边界；移除重复的容器、标题、状态与下载按钮边框。选中算法用细标记与字重指示。

首页左对齐，搜索和常用实验先于完整目录；四个领域为导航分组，不复制或替代算法注册数据。

```text
导航 | 实验入口                     搜索算法
     | 常用实验：示例缩略图 + 实验名称 + 简介
     | 传统视觉    深度学习    工业视觉    视频与三维
     | 算法入口    算法入口    算法入口    算法入口
```

Canny 保持三栏和原有全部交互，图片是最强视觉区域，文字资料接在画布下方。

```text
导航 | Canny 边缘检测                         折叠参数
     | 素材与上传                       | 参数工作台
     | 紧凑查看模式 / 缩放               | Slider + 数字
     | 原始输入          处理结果       | Slider + 数字
     |                                  | 调参预览
     |          深色实验画布             | 运行实验
     |                                  | 参数方案
     | 结果导出 / 简洁学习 Tab           |
```

## 方案复核

移除旧首页的 Hero、统计卡片、编号路径与装饰图案；常用实验使用真实素材缩略图。四个领域以开放列表排版，避免再次变成等尺寸卡片。仅图像画布使用深底，外围保持浅色。青绿色只用于主要操作、焦点与选中标记。样式按页面作用域生效，本轮不推广到其他实验。

## 验收方式

浏览器实际打开首页和 Canny，在 1920×1080、2560×1440 检查空间使用；补查 1440、1024、390、320px。检查搜索、导航、真实运行、并排/滑动/单图、参数折叠、预览、学习 Tab 及输入状态。截图使用真实服务返回的素材与结果；模拟状态另行标注。对照试点前后的画布尺寸、可见边框数量与其他页面样式，确认作用域。

## 实际验收结果

| 项目 | 改版前 | 改版后 |
| --- | --- | --- |
| 1920×1080，单幅图像视口高度 | 410px | 655px |
| 2560×1440，整个图像查看器宽度 | 1560px | 1940px |
| 2560×1440，单幅图像视口高度 | 480px | 951px |
| Canny 页面可见带边框元素 | 74 | 51（减少约 31%） |

边框计数来自相同已完成实验状态下的 `main` 后代元素，不包括导航和伪元素；隐藏元素及透明边框不计入。完整测量保存在 [改版前](visual-lab-before-measurements.json) 和 [改版后](screenshots/visual-lab/measurements.json)。

检查通过：

- `npm run build`。
- `node tests/browser-visual-lab.mjs`：首页搜索与空结果、140 个动态入口、键盘 Enter、两种大屏、1440 / 1024 / 390 / 320px、手机导航与调参；18 张截图，零页面运行错误。
- `node tests/browser-workbench.mjs`：真实 Canny 运行、预览、导出、折叠、三种查看模式、同步缩放、学习 Tab、长文件名、横竖图片比例；慢任务与错误提示使用明确标注的浏览器模拟。
- 灰度实验页的主区域、查看器和参数面板尺寸与改版前一致。Experiment、Viewer、Controls、API、类型定义、公共 theme/style、学习内容与其他页面组件均保持本轮开始时的内容；未修改后端。

截图复查后调整了滑块轨道与滑块按钮、Tab 底线，并取消试点侧栏的位移动画，避免跨屏幕尺寸切换时出现短暂半展开状态。
